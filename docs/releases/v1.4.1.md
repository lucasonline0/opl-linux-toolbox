# OPL Linux Toolbox v1.4.1

This patch release focuses on trustworthy import feedback and stronger checks before changes reach `main`.

## Reliable USBExtreme / UL progress

Large PS2 images that must be split for FAT32 are written by `iso2opl` into `ul.*` chunks. Previous versions displayed the converter's console output as a stage message, but that output may be buffered while the destination files continue growing. This could make a healthy import look frozen.

v1.4.1 measures the actual size of the new UL chunks on the destination drive every 500 ms and reports:

- percentage complete;
- transferred and total size;
- current average throughput;
- estimated time remaining.

The progress source is now the destination filesystem itself, so the UI remains useful even when `iso2opl` stdout is delayed.

## CI and security hardening

Pull requests to `main` now run focused GitHub Actions checks for:

- Electron/TypeScript compilation;
- Angular production build;
- core and UL progress tests;
- shell-script syntax;
- bundled `iso2opl` and license/notice presence;
- npm package-content validation;
- Linux AppImage packaging smoke test;
- CodeQL JavaScript/TypeScript analysis;
- high-severity audits of Electron and Angular production dependencies.

Dependabot also watches the root npm project, Angular project and GitHub Actions dependencies.

GitHub's native Dependency Review is tracked separately because the repository Dependency graph must be enabled before that action can run. The runtime dependency audit remains a blocking CI check in the meantime.

## Distribution

The standard Linux release workflow produces:

- AppImage;
- Debian / Ubuntu package (`.deb`);
- Fedora / openSUSE package (`.rpm`);
- Arch-based package (`.pacman`);
- `SHA256SUMS`.
