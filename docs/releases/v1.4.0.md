# OPL Linux Toolbox v1.4.0

This release focuses on day-to-day OPL library management and makes the built-in Linux updater transparent instead of appearing to freeze while a package is being downloaded and installed.

## What changed

### Update progress

The in-app updater now shows real progress before the application restarts:

1. preparing the release;
2. downloading the package;
3. verifying SHA-256 integrity;
4. installing through the native package path;
5. cleaning temporary files;
6. restarting the application.

An installation error is shown in the same dialog and does not restart the app.

### Artwork repair

- Added an attention-only filter.
- Added missing-asset and artwork-health counts.
- Fixed **Repair missing** so it queues only missing artwork.
- Kept an explicit **Refresh all** path for intentional full refreshes.
- Improved feedback after checks, repairs and manual imports.

### OPL CFG management

Game details now include an OPL settings panel for PS1/PS2 disc entries:

- compatibility Mode 1–8 toggles;
- VMC slot 0 assignment;
- VMC slot 1 assignment;
- preservation of CFG keys the app does not understand.

### Virtual Memory Cards

- Card count and allocated-space summary.
- Search/filter for existing cards.
- Quick 8 MB presets.
- Clearer relationship between VMC files and per-game CFG assignment.

### Dashboard and navigation

- Sidebar groups are now **Library**, **Assets** and **Tools**.
- Dashboard health information can be refreshed manually.
- Added direct actions for Health & Repair, Artwork and Memory Cards.

## Safety

The updater still accepts release assets only from allowed GitHub hosts and verifies the selected package against `SHA256SUMS` before installation. Temporary update files are removed on failure.

CFG editing changes only the OPL compatibility and VMC keys exposed in the UI while retaining unrelated CFG entries.

## Linux downloads

The release pipeline publishes:

- `opl-linux-toolbox-1.4.0-x86_64.AppImage`
- `opl-linux-toolbox-1.4.0-x86_64.deb`
- `opl-linux-toolbox-1.4.0-x86_64.rpm`
- `opl-linux-toolbox-1.4.0-x86_64.pacman`
- `SHA256SUMS`
