# Community promotion kit

This file keeps public announcements consistent, factual and easy to adapt for different PS2 communities.

## Core positioning

**OPL Linux Toolbox** is a Linux-first desktop manager for Open PS2 Loader libraries with a strong focus on safe file operations and native Linux integration.

Key points worth highlighting:

- PS2 DVD/CD, PS1/POPS and APPS/ELF library management.
- ISO, ZSO, CUE/BIN and ELF import workflows.
- Atomic `.part` copies, optional SHA-256 verification and targeted rollback.
- FAT32 UL/USBExtreme handling for large PS2 games.
- Artwork, CFG and VMC management.
- Linux mount discovery, filesystem/capacity inspection and safe unmounting.
- AppImage, `.deb`, `.rpm` and Arch/Pacman packages.
- One-command installer with checksum verification.
- Open source under GPL-3.0, with OrbitOPL Toolbox origins and credits preserved.

## Reddit / r/ps2homebrew

### Suggested title

OPL Linux Toolbox — a Linux-first Open PS2 Loader library manager with safe imports, artwork, CFG/VMC and native packages

### Suggested post

I have been working on **OPL Linux Toolbox**, an open-source desktop manager for Open PS2 Loader libraries focused specifically on making the Linux experience safer and more complete.

It can manage PS2 DVD/CD, PS1/POPS and APPS libraries, import ISO/ZSO/CUE/BIN/ELF files, fetch artwork, edit CFG data, manage VMCs and handle FAT32 UL/USBExtreme installs.

The part I wanted to improve most is file safety: imports use temporary `.part` files, optional SHA-256 verification and targeted rollback instead of treating a game transfer as a blind copy. It also detects mounted Linux storage, reports filesystem/capacity information and can safely unmount supported devices.

Linux builds are available as AppImage, `.deb`, `.rpm` and Arch/Pacman packages, with a checksum-verified one-command installer.

The project is based on and evolved from OrbitOPL Toolbox by Luden02; the upstream GPL-3.0 credits and contributor history are preserved.

GitHub: https://github.com/lucasonline0/opl-linux-toolbox

Feedback from people who actively use OPL, MX4SIO/USB libraries or Linux for PS2 management would be especially useful. Bug reports and small contributions are welcome.

## Promotion rules

- Do not claim affiliation with the Open PS2 Loader project, Sony, PlayStation, ConsoleMods or OrbitOPL.
- Do not claim the project is "official".
- Do not frame the project as a source for commercial game downloads.
- Keep upstream attribution visible.
- Prefer concrete features over claims such as "best" or "ultimate".
- Ask for testing and technical feedback rather than only asking for stars.
